## Описание
`GitHub User Finder` — настольное GUI-приложение на Python (`tkinter`) для поиска пользователей GitHub через API,
отображения результатов и сохранения выбранных пользователей в избранное.

Основные возможности:
- поиск пользователей GitHub по строке запроса;
- отображение результатов в виде списка;
- добавление пользователя в избранное;
- удаление пользователя из избранного;
- автоматическое сохранение избранного в `favorites.json`;
- проверка ввода: пустое поле поиска запрещено.

## Как использовать API
Приложение обращается к endpoint GitHub Search API:

- `GET https://api.github.com/search/users?q=<query>&per_page=30`

Заголовки запроса:
- `Accept: application/vnd.github+json`
- `User-Agent: GitHub-User-Finder-App`

Пример ответа содержит массив `items`, где для каждого пользователя берутся:
- `login` — логин пользователя;
- `html_url` — ссылка на профиль.

## Примеры использования
### 1. Запуск приложения
```bash
python main.py
```

### 2. Поиск пользователя
1. Введите, например: `octocat`
2. Нажмите кнопку **Поиск** (или Enter)
3. В списке слева появятся найденные пользователи

### 3. Добавление в избранное
1. Выберите пользователя в результатах поиска
2. Нажмите **Добавить в избранное**
3. Пользователь появится в списке справа и будет сохранен в `favorites.json`

### 4. Удаление из избранного
1. Выберите пользователя в списке избранного
2. Нажмите **Удалить из избранного**
